What's new
----------
• Start Both — start TPMS Board and SDR Receiver together (one RTL-SDR at a time)
• Comparative Analysis — Compare Excel / Compare PDF from the header

• Live Board table columns for SDR compare result and reason
• Multi-page comparative PDF tables with visible column headings
