TPMS Suite 6.0

What's new
----------
• RTL-SDR detection uses the bundled rtl_433 and its DLLs on Windows
• Combined SDR Receiver + TPMS Board suite for Windows
• Full rtl_433 catalog, IQ/URH tooling, comparative Excel/PDF reports
• Chapter 4.0 Query Version (0x40) — read board firmware from the UI
• Progress pipeline cards with per-step Logs
• Board RX is USB-TTL only (J-Link / JTAG removed)
