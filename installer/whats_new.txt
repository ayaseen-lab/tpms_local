TPMS Suite 2.0

What's new
----------
• Default Hamaton full catalog (data/Hamaton_database_*.xlsx)
• Board USB-TTL RX first — J-Link / JTAG is optional (Windows client path)
• SDR OK only from stock rtl_433 library telemetry (no flex / no guessing)
• Board waits for live SDR compare before the next ABC codes
• Related-ID matching between Board and rtl_433
• Windows: Start TPMS Suite.bat, Setup_Windows.bat, Build_Windows_Installer.bat,
  and TPMS_Suite.exe launcher

Notes
-----
Windows clients: plug USB board + RTL-SDR, run Setup_Windows.bat once, then
Start TPMS Suite.bat (or TPMS_Suite.exe). J-Link is not required when the
board replies on USB RX.

To build the full packaged installer on a Windows PC:
  Build_Windows_Installer.bat
