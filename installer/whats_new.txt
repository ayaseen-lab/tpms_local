TPMS Suite 4.0

What's new
----------
• Chapter 4.0 Query Version (0x40) — read board firmware from the UI
• Firmware is the primary field (TPMS software version), with HW / Boot /
  Trigger / Prog DB shown alongside
• Query firmware button on the Board tab (no full run required)
• Progress tab Connect step shows the same version report
• Progress pipeline cards with per-step Logs and Clear all
• Board settles SDR listen after Board OK; Excel stock library path fixes

Notes
-----
Windows clients: plug USB board + RTL-SDR, run Setup_Windows.bat once, then
Start TPMS Suite.bat (or Fyrqom_TPMS_Suite.exe). J-Link is not required when the
board replies on USB RX.

To build the full packaged installer on a Windows PC:
  Build_Windows_Installer.bat
